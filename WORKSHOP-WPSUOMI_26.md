- Event: [WP Suomi 26](https://wpsuomi.fi/speaker/milana-cap/)

## Setup steps

- Install the latest WordPress in your favorite local environment.
- Download/clone this repo.
- Make sure to place two plugins from this repo into your local `wp-content/plugins/` dir:
    1. wpgems-inaccessible-blocks, and
    2. wpgems.
- Go to your local WordPress instance and activate these two plugins.
- Create a post and add `Inaccessible Form` block. 
- The workshop starts here.
